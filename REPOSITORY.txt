# Shared agent skills

This repository is the shared source for Codex and Pi skills on Windows and WSL.

- Windows path: `D:\dev\skills`
- WSL path: `/mnt/d/dev/skills`
- Codex repository skill entrypoint: `.agents/skills`
- Each skill directory under `.agents/skills` contains a required `SKILL.md`.
- Keep skill names lowercase and use letters, digits, and hyphens only.
- Reference scripts, assets, and documentation with paths relative to the skill directory.

The `.agents/skills` directory is the only source of truth. To make this set
available from every repository on a machine, run one of these after cloning:

- Windows PowerShell: `./scripts/install-global.ps1`
- WSL: `./scripts/install-global.sh`

The scripts create the user-level `$HOME/.agents/skills` link used by Codex.

Runtime state and npm packages live elsewhere under `D:\dev`; they are intentionally not part of this repository.
